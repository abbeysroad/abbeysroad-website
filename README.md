# NordisTravel Premium Scandinavia Vacations

NordisTravel is a premium, high-fidelity single page application (SPA) designed to showcase Scandinavian travel itineraries. The website is crafted to display beautiful routes across Sweden, Norway, Denmark, and Finland with interactive maps, pricing calculators, and dynamic image sliders.

---

## 🎨 Core Design System & Features

- **Dynamic Interactive Map Deck**: Animates a route tracing the traveler's journey in SVG as they scroll down the daily timeline.
- **Responsive Multi-Image Carousels**: Built for both desktop and mobile viewports. On desktop, slides can display either a single full-width image or a `double` layout showing two side-by-side images. On mobile, slides are dynamically flattened to show one image per view.
- **Dynamic Price Calculator**: Allows users to select dates, cabin classes, and supplement options to see live price adjustments.

---

## 📜 Project Rules & Asset Guidelines

To maintain the high-fidelity comfort and premium status of the NordisTravel brand, all developers must adhere to the following rules regarding content and visual assets:

### 1. Accurate & Destination-Specific Images (CRITICAL)
- **Do not reuse images** that do not represent the actual destination, landmark, or specific experience described in the daily itinerary.
- **Do not reuse images across itineraries** just because the descriptions or items sound similar (e.g., do not reuse a Copenhagen pastry photo for a Swedish fika, or an Oslo overnight cruise photo for a Silja Line cruise). 
- Every visual asset must clearly and carefully represent the actual look, cultural differences, unique architecture, and specific geographical location of the destination in that itinerary.

### 2. High Resolution & Premium Aesthetics
- Use curated, high-fidelity, realistic travel photographs representing clean Nordic environments.
- Ensure all captions and overlay titles accurately detail the exact visual subject displayed in the slide.
- Avoid generic stock photos or placeholders that feel disconnected from the itinerary's written flow.
